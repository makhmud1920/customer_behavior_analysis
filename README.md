📊 Customer Behavior Dashboard
Ushbu loyiha mijozlarning xarid qilish odatlari, demografik ko'rsatkichlari va mahsulot toifalariga bo'lgan qiziqishlarini tahlil qilish uchun yaratilgan Power BI dashboardidir. Ma'lumotlar vizuallashuvi biznes qarorlarini qabul qilishda muhim insightlarni taqdim etadi.
🚀 Loyiha Maqsadi
Dashboard quyidagi savollarga javob berishga qaratilgan:
Mijozlarning umumiy soni va ularning obuna (Subscription) holati qanday?
Qaysi mahsulot toifalari eng ko'p daromad keltirmoqda?
Yosh guruhlari bo'yicha xarid qilish tendentsiyalari qanday farqlanadi?
Mavsumiy savdo ko'rsatkichlari qaysi vaqtda eng yuqori bo'ladi?
🛠 Ishlatilgan Texnologiyalar
Power BI Desktop – Ma'lumotlarni modellashtirish va vizuallashuv uchun.
DAX (Data Analysis Expressions) – Murakkab hisob-kitoblar va o'lchovlar (Measures) yaratish uchun.
Power Query – Ma'lumotlarni tozalash va transformatsiya qilish (ETL) uchun.
📌 Asosiy Ko'rsatkichlar (KPIs)
Dashboardda quyidagi asosiy metrikalar aks ettirilgan:
Number of Customers: 3.889K (Umumiy mijozlar soni).
Average Purchase Amount: $59.76 (O'rtacha xarid summasi).
Average Review Rating: 3.75 (Mijozlar tomonidan berilgan o'rtacha baho).
Subscription Status: Mijozlarning 7.29% obunachi, 92.71% esa oddiy foydalanuvchilar.
📈 Vizual Tahlillar Tavsifi
Revenue by Category: Clothing (Kiyim-kechak) eng yuqori daromad keltiruvchi kategoriya ekanligini ko'rsatadi.
Sales by Season: Savdolar mavsumlar kesimida (Spring, Fall, Winter, Summer) deyarli bir xil taqsimlangan, lekin bahor va kuz mavsumlarida biroz ustunlik bor.
Revenue/Sales by Age Group: "Young Adult" va "Middle-aged" guruhlari eng faol xaridorlar hisoblanadi.
Interactive Filters: Chap tomondagi filtrlar yordamida ma'lumotlarni Gender, Category, Subscription Status va Shipping Type bo'yicha saralash mumkin.
